# Ellieo 베트남 피벗 브리프 (결정 사항)

원본: docs/specs/ellieo_vietnam_pivot_prompt.md (v3, 2026-10-30) 1부를 그대로 옮김. 수정은 원본과 함께 한다.

## 1. 사업 방향
- Ellieo를 "미국 유학생 생활 플랫폼"으로 개편한다. 서비스 구성은 Misaeng과 같다(면접·취업 후기, OPT·비자 정보, 하우징, 커뮤니티, 포인트, 나중에 구독).
- 첫 공략 대상은 뉴욕의 베트남 유학생이다. 베트남은 미국 유학생 출신국 상위 5위권이고 빠르게 늘고 있는 시장이다(수치는 IIE Open Doors 최신 자료로 재확인 예정).
- 기존 Ellieo의 방향(미국 전역 룸메이트·렌트 플랫폼, 3~4년 후 엑싯)은 종료한다. 룸메이트·렌트 기능은 하우징 모듈로 흡수한다.
- 목표는 운영자가 미국에 상주하지 않아도 돌아가는 안정적인 수입 구조다. 초기 수입은 브로커리지(뉴욕 렌트)와 연결되고, 사용자가 충분히 모이면 구독을 연다.
- Misaeng(ko, en)은 그대로 유지한다. 일본 유학생 대상 서비스는 나중에 별도 브랜드로 만든다. 다른 언어권도 각각 별도 서비스로 개발한다.
- 초기 운영은 운영자 1인(Simon)이 맡는다. 베트남어 운영 인력 채용은 나중의 일이다.
- Ellieo는 웹(ellieo.com)으로만 먼저 개발하고 운영한다. 기존 Ellieo 앱은 이번 범위에서 수정하지 않으며, 네이티브 앱 개편은 웹 반응을 본 뒤 결정한다.

## 2. 브랜드와 언어
- 브랜드명은 Ellieo 유지. 베트남 유학생은 베트남어 이름의 사이트를 사기로 의심하는 경향이 있어, 영어 브랜드명이 신뢰에 유리하다.
- Ellieo는 USPTO 등록 상표(등록번호 8509979, 9류·45류)다. 화면에 ® 사용 가능.
- 언어: vi(기본), en 두 개만 운영한다.
- vi, en 외 언어(ja, zh-CN, zh-TW, id, ko 등)는 Ellieo에서 삭제한다. 기능 플래그로 남기지 않는다. (사용자 계정과 원문 글은 삭제하지 않는다. 2부 A 참고)
- 태그라인은 국적을 한정하지 않는다. 영어를 쓰는 동남아 학생(필리핀, 싱가포르, 말레이시아 등)도 영어 화면으로 쓸 수 있게 열어둔다.
  - vi: "Ellieo · Cộng đồng du học sinh tại Mỹ"
  - en: "Ellieo · The community for international students in the US"
- 마케팅은 베트남에 집중(뉴욕 학교 VSA, 베트남 유학생 페이스북 그룹, LinkedIn)하되, 브랜드 문구는 넓게 유지한다.

## 3. 신뢰가 최우선인 커뮤니티
Ellieo의 목표: 모든 구성원이 인증된, 서로 믿을 수 있는 유학생 커뮤니티를 만들고 키우는 것.

### 가입과 인증
- 가입 조건: 학교 이메일 또는 직장 이메일 인증 필수. Ellieo에서는 인스타그램 인증을 제공하지 않는다.
- 비가입자: 공개 정보(후기 제목과 회사명, 비자 공개 정보, 하우징 매물, 사기 유형 가이드 등) 열람 가능.
- 인증 사용자만: 글쓰기, 댓글, 메시지, 하우징 문의, 커피챗.

### 학교 이메일
- Ellieo는 뉴욕시(NYC) 지역 학교 도메인만 허용한다. 학교 도메인 목록은 ERP에서 관리하며 브랜드별 허용 지역을 설정할 수 있어야 한다.
- 허용 지역 밖 학생은 "학교 추가 요청"을 보낼 수 있다. 이 요청은 다음 확장 지역을 정하는 데이터로 쓴다.

### 직장 이메일 (강한 회사 인증)
- 자동 거절: 개인 메일, 일회용 메일 도메인
- 자동 확인: 메일 서버(MX) 존재, 도메인 등록일
- 자동 승인: 등록된 회사 목록과 도메인 일치
- 수동 심사: 목록에 없는 도메인, 등록 1년 이내 도메인. 회사 웹사이트, LinkedIn 회사 페이지 확인, 필요 시 사용자 LinkedIn 프로필 링크 확인
- 승인된 회사는 회사 목록에 추가해 다음부터 자동 승인
- 처음 보는 도메인에서 가입이 급증하면 자동 보류
- 배지는 "직장인 인증"만 기본 표시, 회사명은 본인 선택 시에만 공개
- 1년마다 재확인, 실패 시 배지 만료

### 신고와 처리 약속
초기에는 운영자 1인이 처리하므로 지킬 수 있는 기준으로 시작하고, 인력이 생기면 줄인다. 모든 기준 시간은 config로 관리한다.

| 신고 유형 | 초기 처리 약속 | 목표 | 즉시 조치 |
|---|---|---|---|
| 사기 의심 (선입금 요구, 가짜 집주인, 가짜 채용, 기관 사칭) | 48시간 | 24시간 | 인증 사용자 신고가 기준 수 이상이면 검토 전 자동 비공개 |
| 개인정보 노출 | 48시간 | 24시간 | 신고 즉시 비공개 |
| 스팸, 광고, 복붙 | 72시간 | 72시간 | |
| 기타 규칙 위반 | 72시간 | 72시간 | |
- 신고자에게 처리 상태 표시: 접수, 검토 중, 조치 완료
- 월간 처리 신고 수를 사용자 화면에 공개
- 확정 삭제 시 신고자 포인트 지급 (misaeng_points_spec.md 기준)
- 화면에 표시하는 처리 약속 문구는 config 값과 자동으로 일치해야 한다

### 신뢰 표시 (모든 Ellieo 페이지)
- 하단: "Operated by Misaeng LLC, New York", 뉴욕주 부동산 라이선스 정보, 소속 브로커리지
- 하우징: 선입금 없음, OP 매물은 세입자 중개 수수료 없음
- 운영팀 소개, 베트남어 상담 담당자, 파트너 학생회(VSA) 영역: 구조만 만들고 기본 숨김. 인력과 파트너가 생기면 ERP에서 켠다
- "Ellieo 공식 원칙" 페이지 (내용은 추후 제공. 예: Ellieo 직원은 DM으로 돈이나 서류를 요구하지 않는다)
- 베트남어 "미국 유학생 사기 유형 가이드" 공개 페이지 (비가입자 열람 가능, 내용은 추후 제공)

### 소개 문구 초안 (베트남어는 원어민 검수 예정, 처리 시간은 config 값으로 치환)

Together, we keep this community safe and trustworthy. See something suspicious? Report it, and our team will review it within {sla_hours} hours."
- vi: "Ellieo là cộng đồng du học sinh tại Mỹ, nơi mọi thành viên đều được xác minh bằng email trường học hoặc email công ty. Chúng ta cùng nhau xây dựng một cộng đồng an toàn và đáng tin cậy. Nếu thấy điều gì đáng ngờ, hãy báo cáo ngay, đội ngũ Ellieo sẽ kiểm tra trong vòng {sla_hours} giờ."

## 4. 콘텐츠 공유 원칙
- 커뮤니티 게시판: 브랜드별 완전 분리
- 하우징 매물: misaeng.com/nyc와 같은 데이터를 공유하고 Ellieo에서는 vi, en으로만 표시한다
  - 매물 설명은 베트남어 번역본 자동 생성, 주소·가격·수수료·라이선스 등 필수 항목은 원래 값 그대로 표시
  - Ellieo 경유 문의는 같은 브로커리지 팀으로 연결하고 리드 출처를 ellieo로 기록
  - 국적·언어에 따라 매물을 다르게 보여주지 않는다 (Fair Housing)
- 면접·취업, OPT·비자 후기
  - 초기(성장 단계): 구독·결제 기능은 구현하되 config로 비활성화한 상태로 출시한다
  - 초기에는 Ellieo 자체 후기와 Misaeng 후기 번역본 모두 Misaeng과 같은 열람 규칙(무료 기간, 이후 포인트)으로 제공한다
  - Misaeng 후기는 작성자가 "번역 게시"와 "구독 콘텐츠 포함"에 모두 동의한 글만 Ellieo에 노출한다 (나중에 구독 콘텐츠로 전환할 수 있게)
  - 유료 전환 시(사용자가 충분히 모인 뒤): config로 Misaeng 후기 번역본을 구독 전용으로 바꾸고, 비구독자에게는 회사명, 직무, 결과, 본문 앞부분 미리보기만 노출한다. 전환 2~4주 전 공지 기능 포함
- 누구나 무료: 하우징 매물, 비자 공개 정보, 사기 유형 가이드
- 국적 표시, 국적 필터는 어디에도 두지 않는다. 커뮤니티는 언어 기준이며 누구나 가입 가능

## 5. 초기 커뮤니티 구조와 콘텐츠
- 게시판은 좁게 시작한다: 면접·취업 후기, OPT·비자, 하우징(룸메이트·서블렛 포함), 질문 게시판, 맛집. 글이 적은 게시판이 많으면 비어 보인다.
- 첫 방문자가 볼 초기 콘텐츠: 동의를 받은 Misaeng 후기 번역본, 정부 공개 데이터 기반 비자 정보, 사기 유형 가이드, 뉴욕 하우징 매물
- 가입 직후 가벼운 첫 행동 안내("첫 질문 올리기", "내 학교 정보 공유하기")와 포인트 연결
- 초기 후기 목표: 2027년 1분기 말까지 Ellieo 자체 면접·취업, 비자 후기 100개
- 후기 확보 경로: LinkedIn 콜드 메시지(베트남계 현직자), 작성자의 동료 소개, 뉴욕 학교 VSA와 졸업생 네트워크, 브로커리지 베트남 고객

## 6. 포인트, 구독, 등급, 지표
- 포인트: misaeng_points_spec.md와 같은 구조(적립, 사용, 등급, 신고 보상). 표시 이름 vi "Điểm Ellieo", en "Ellieo Points"
- 추천안: 포인트 엔진은 공유하되 잔액과 원장은 브랜드별 분리 (point_ledger에 brand 필드). 설계 문서에서 공유안과 비교해 결정 항목으로 올린다
- 구독: 브랜드별로 분리. 초기에는 비활성화. Ellieo 구독 가격과 혜택은 config로 별도 설정
- 이벤트 기록에 brand, locale, platform 필드. 사용자에게 signup_brand, preferred_locale 저장
- Ellieo 대시보드: 베트남어 신규 가입, 인증 완료율, 주간 재방문, 베트남어 자발적 게시글 수, Ellieo 자체 후기 수(목표 100 대비), 번역 후기 열람 수, Ellieo 유입 하우징 문의, 신고 처리 현황, 후기 요청 경로별 전환
- 출시 후 4~6주 검증 기간을 두고 위 지표로 판단한다

## 7. 법무
- 이용약관, 개인정보처리방침: 영어본이 기준, 베트남어 번역본 제공
- 계정·포인트 공유 범위와 콘텐츠 번역 노출을 고지하고 동의를 받는다
- 재동의는 기존 consent logs 버전 관리를 사용한다
- 약관과 개인정보처리방침의 베트남어 번역본은 기계 번역만으로 공개하지 않고, 공개 전 사람이 검수한다
- 하우징·채용 관련 광고를 낼 때 국적이나 출신으로 대상을 고르지 않는다(Fair Housing, 고용 차별 규정, Meta 특별 광고 범주). 베트남 학생 대상 홍보는 VSA, 커뮤니티 그룹, 베트남어 콘텐츠 같은 자연 경로를 쓴다

## 8. 웹 디자인 (Ellieo)
- 정보 구조와 기능은 misaeng.com/nyc를 따르되, 화면 디자인은 Ellieo 브랜드와 베트남어 특성에 맞게 새로 구성한다.
- 컴포넌트와 기능은 공유하고, 브랜드 테마(색, 로고, 글꼴, 간격)는 브랜드별로 분리한다.
- 모바일 우선 설계. 홈 화면 추가(PWA) 지원. 공유 미리보기(Open Graph)를 vi와 en으로 설정한다(페이스북, 메신저, Zalo 공유 대비).
- 로그인 유지, 모바일 데이터 환경에서 빠른 첫 화면 로딩.

### 글꼴
- Be Vietnam Pro (Google Fonts, OFL). vi와 en 모두 같은 글꼴 사용.
- 문자 세트: latin, vietnamese만 로드. 굵기: 400(본문), 500(강조), 600(소제목), 700(제목).
- 본문 줄 간격 1.6 전후. 대체 글꼴은 시스템 글꼴로 연결.
- Next.js 예시:
```ts
import { Be_Vietnam_Pro } from "next/font/google";

export const beVietnamPro = Be_Vietnam_Pro({
  subsets: ["latin", "vietnamese"],
  weight: ["400", "500", "600", "700"],
  display: "swap",
  variable: "--font-ellieo",
});
```
```css
:root {
  --font-ellieo-stack: var(--font-ellieo), system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
}
body {
  font-family: var(--font-ellieo-stack);
  line-height: 1.6;
}
```

### 베트남어 대응
- 베트남어 문장은 한국어보다 길다. 고정 폭 레이아웃 금지. 버튼, 탭, 메뉴는 글자 길이에 따라 늘어나게 하고, 메뉴는 짧은 단어와 아이콘을 함께 쓴다.
- 말줄임은 단어 단위로 한다.
- 성조 기호(ệ, ặ, ỗ 등)가 위아래 줄과 겹치지 않도록 줄 간격을 넉넉하게 둔다.
- 성조 기호를 무시하는 검색: "nha tro"로 검색해도 "nhà trọ"가 나와야 한다.
- 날짜는 일/월/년 순서로 표시. 가격은 미국 매물이므로 미국 표기($2,500) 유지.
- 커뮤니티 표시 이름은 닉네임 기본(베트남 성씨는 Nguyễn 등 중복이 많음).
- 화면 검수는 반드시 실제 베트남어 문장으로 한다. 자리 표시 문구로 검수하지 않는다.

## 9. 검토 필요 항목 (추천안. 설계 문서의 "결정이 필요한 항목"으로 올린다)
1. 첫 출시 범위 축소 (1인 운영 기준)
